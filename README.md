# MoTec M1 Build / Tune / Display Creator Version Control


## Installing New M1 Build Projects:
* To update your M1 Build Local Project, first make sure you have installed version 1.4.0.239 of MoTec M1 Build. Other versions have not been tested.

* Verify you are in the Projects Directory:           
```(C:\Users\[YOUR-USER]\Documents\MoTeC\M1\Build\Projects\)```

* Download, & Drag & Drop the ```CC-EV1 Michigan 2027``` zip folder provided in this repository to the Projects Directory.

* Unzip the ```CC-EV1 Michigan 2027``` folder, your Projects directory should look like this:

![folder tree](/assets/Screenshot%202026-10-10%20135815.png)

* Open M1 Build, if the project does not show up in the inital splash screen, click ```Open a Project```
  
* Search for the ```CC-EV1 Michigan 2027``` project, and select the latest version. Open the Project:

![m1build](/assets/Screenshot%202026-10-10%20140144.png)

* Pat yourself on the back, you just installed the newest ```CC-EV1 Michigan 2027``` M1 Build Package.
